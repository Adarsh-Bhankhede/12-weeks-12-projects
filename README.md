## 📂 Completed Projects

### Week 01 — 🎲 Dice Rolling Game

A simple Python program that simulates rolling two dice. The program generates random numbers between **1 and 6**, displays the results, and allows the user to roll again.

**Concepts learned:**

* `random` module
* `random.randint()`
* `while` loop
* `if-elif-else`
* User input
* Variables
* Counter
